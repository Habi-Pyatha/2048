# 2048 Game 🎮

A simple, web-based clone of the classic **2048 puzzle game**.  
Play it live here: [**Demo**](https://habi-pyatha.github.io/2048/)

## 🎯 Objective
Slide numbered tiles on a 4×4 grid to combine them and create the **2048 tile**.  
- Use arrow keys (↑ ↓ ← →) to move tiles.  
- When two tiles with the same number touch, they merge into one.  
- Keep combining to reach 2048 (or beyond).

## 🚀 Features
- Clean and minimal design  
- Smooth tile animations  
- Supports keyboard controls  
- Works directly in the browser (no installation)

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**
